# Доступ к админ-панели MakeTrades

## Данные для входа

Администратор успешно создан!

- **URL админки:** `https://maketrades.info/admin.html`
- **Email:** хранится в вашем менеджере паролей
- **Пароль:** хранится в вашем менеджере паролей

Учётные данные намеренно не хранятся в репозитории. Управлять админами
можно через Supabase → Authentication → Users и таблицу `admin_users`.

## Первый вход

1. Откройте `/admin.html` в браузере
2. Введите email и пароль администратора
3. Если пароль утерян — сбросьте его в Supabase → Authentication → Users

## Возможности админ-панели

### 1. Локализация
- Управление всеми переводами на сайте
- Редактирование текстов кнопок, надписей, цен
- Поддержка 5 языков: RU, EN, DE, UK, ZH

### 2. Картинки
- Управление всеми изображениями сайта
- Редактирование URL и alt-текстов
- Категоризация изображений

### 3. Блог
- Управление всеми 500 статьями блога
- Редактирование контента
- Управление публикацией и датами
- Фильтрация по языку и статусу

## Безопасность

- Все данные защищены Row Level Security (RLS)
- Только администраторы могут изменять контент
- Пользователи могут только читать публичные данные

## Важно

**СОХРАНИТЕ ЭТИ ДАННЫЕ В БЕЗОПАСНОМ МЕСТЕ!**

После первого входа смените пароль на более сложный.
